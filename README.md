# hw6 — SENTRY-C1 Test Automation

Домашнє завдання курсу Embedded QA Engineer: автоматизація перевірки
дефектів прошивки **SENTRY-C1** (ESP32-S3) через UART CLI за допомогою
Python + `pyserial`.

Пристрій керується повністю через послідовний порт (115200 8N1), опис
усіх команд і поведінки — у PRD прошивки (`fw_2/SENTRY-C1_PRD.md` в
репозиторії курсу).

## Файли

| Файл | Призначення |
|------|-------------|
| `explore_script.py` | Пошук COM-портів + мінімальне ручне підключення, шле `help\r\n` і друкує сиру відповідь (без обгортки в клас) |
| `device_driver.py` | Клас `DeviceDriver` — відкриття/закриття порту, надсилання команд, читання відповіді, логін |
| `test_bugs.py` | Автотести |

## Запуск

Перед запуском переконайся, що плата підключена і жодна інша програма
(наприклад `monitor.bat`/`flash.bat`) не тримає відкритим COM-порт —
порт може бути зайнятий лише однією програмою одночасно.

Розвідувальний скрипт (Частина 1):

```bash
python explore_script.py
```

Автотести:

```bash
python test_bugs.py
```

Результат кожного тесту (PASS/FAIL з поясненням) виводиться в
підсумку в кінці запуску `test_bugs.py`.
